# Aphasia Data

This folder contains the main notebook set used for the Aphasia project.

## Notebooks

- `Aphasia_analysis.ipynb` — Aphasia Treatment Analysis: Evaluating the BEARS Framework
- `Aphasia_BEARS_Treatment_Analysis.ipynb` — BEARS Treatment Analysis & Dashboard Generation
- `Aphasia_BKT_vs_ExGaussian_Comparison.ipynb` — Parallel Modeling of Mastery and Stability in Aphasia Recovery
- `Aphasia_dosage_prediction.ipynb` — Clinical Decision Support: Dosage to Mastery Forecasting
- `Aphasia_RandomForest.ipynb` — Aphasia Recovery Forecasting: 1-Month Follow-Up Analysis
- `Aphasia_NeuralNetwork.ipynb` — Aphasia Recovery: Neural Network Maintenance Forecasting
