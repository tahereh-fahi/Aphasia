# Aphasia

Adaptive aphasia rehabilitation platform with interactive naming practice, semantic feature verification, and data-driven treatment analytics.

Live demo: https://aphasia-app-beige.vercel.app/

## What this repository includes

- the deployed Aphasia therapy website
- a curated set of analysis notebooks
- selected figures and result summaries
- a lightweight, presentation-friendly project structure

## Project highlights

- interactive language practice workflow
- semantic feature verification support
- treatment progress and recovery analysis
- notebook-based modeling and evaluation

## Repository structure

- `Aphasia Data/` — notebooks and supporting visual material
- `Aphasia Selected Results/` — selected output figures for presentation
- `website/` — a short note pointing to the live app

## Notes

This repo is intentionally curated for portfolio presentation. It keeps the focus on the website, analysis notebooks, and selected results rather than the full research workspace.
