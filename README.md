# Aphasia Adaptive Therapy App

A curated GitHub-ready snapshot of the Aphasia project: the live web app plus a focused research slice from the 06-Aphasia workspace.

Live demo: https://aphasia-app-beige.vercel.app/

## What this repo shows

- The deployed aphasia therapy interface, including naming practice, semantic feature verification, and analytics.
- A curated set of analysis notebooks from the 06-Aphasia workspace.
- Key result figures and the core treatment datasets used in the notebooks.

## Selected notebooks

- `Aphasia Data/Aphasia_analysis.ipynb` — Aphasia Treatment Analysis: Evaluating the BEARS Framework
- `Aphasia Data/Aphasia_BEARS_Treatment_Analysis.ipynb` — BEARS Treatment Analysis & Dashboard Generation
- `Aphasia Data/Aphasia_BKT_vs_ExGaussian_Comparison.ipynb` — Parallel Modeling of Mastery and Stability in Aphasia Recovery
- `Aphasia Data/Aphasia_dosage_prediction.ipynb` — Clinical Decision Support: Dosage to Mastery Forecasting (Optimized)
- `Aphasia Data/Aphasia_RandomForest.ipynb` — Aphasia Recovery Forecasting: 1-Month Follow-Up Analysis
- `Aphasia Data/Aphasia_NeuralNetwork.ipynb` — Aphasia Recovery: Neural Network Maintenance Forecasting
